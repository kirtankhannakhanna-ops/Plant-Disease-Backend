# Kissan Dost AI - Plant Disease Identification System 🌿

A Final Year Project developed to help farmers instantly detect and manage plant diseases using a multilingual AI-powered web application. 

## 🌟 Key Features
* **Disease Detection:** Classifies plant diseases from leaf images using uploaded images or live camera.
* **Multilingual Support:** Fully accessible in English, Urdu, Sindhi, and Punjabi.
* **Agri-Tools:** Includes Live Weather Tracking and a Fertilizer Calculator.
* **Analytics Dashboard:** Saves scan history and generates farm health summaries.

## 💻 Tech Stack
* **Language & Interface:** Python, Streamlit
* **Machine Learning:** TensorFlow, Keras, MobileNetV2, NumPy, Pandas, Pillow
* **Database & APIs:** SQLite, Requests, gTTS (Google Text-to-Speech)
